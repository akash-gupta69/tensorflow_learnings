# Program Neural Networks with TensorFlow

This repository documents my progress through Google's **Program Neural Networks with TensorFlow** learning pathway. It includes the notebooks, experiments, and exercises I complete while working through the program.

Throughout the pathway, I am building my understanding of neural networks with TensorFlow, starting with basic machine learning concepts and gradually moving toward computer vision and Convolutional Neural Networks (CNNs) for image classification.

## Repository Contents

- **01 - The Hello World of Machine Learning**: Basic introduction to machine learning principles and model building with TensorFlow.

- **02 - Introduction to Computer Vision**: Writing code to recognize fashion items using computer vision techniques.

- **03 - Introduction to Convolutions**: Exploring how convolutions and pooling work to extract features from images.

- **04 - Convolutional Neural Networks (CNNs)**: Implementing CNNs to improve image classification accuracy.

- **05 - Complex Images**: Training models on more intricate datasets and handling real-world image structures.

- **06 - Use CNNs with Larger Datasets**: Scaling CNN models to process larger and multi-class image datasets.

## Prerequisites

- Python 3.x
- TensorFlow 2.x
- Jupyter Notebook / Google Colab
